# London News card + discovery update

Replace the matching files in your repository:

- `src/pages/index.astro`
- `src/styles/global.css`
- `scripts/fetch_news.py`
- `scripts/sources.py`
- `requirements.txt`

## What changed

- Article reader/body is flat again. Cards only apply to story collections and related-story cards.
- Desktop card layout:
  - first 3 visible stories are full-width two-column cards
  - every story after that is a two-card-per-row layout
  - all card art is cropped in a 1:1 frame
- Missing artwork no longer creates a giant empty media panel.
- Card images use a lightweight focal-point/saliency calculation generated by the GitHub Action.
- The focal analysis is lazy and capped at 24 new images per refresh so the Action stays light.
- CTV now discovers stories directly from `https://www.ctvnews.ca/london/` and only accepts `/london/article/` links.
- Added 104.7 Heart FM using its RSS feed at `https://www.heartfm.ca/news/local-news/feed.xml`.
- London Police and City of London are now direct page sources rather than Google proxies.
- Added the supplied Google News London topic/section as a supplemental discovery feed.
- Google-discovered stories retain the actual publisher name, so the Sources page can hide/show those publishers normally.
- Direct-feed and Google-discovered copies are deduplicated by canonical URL and near-time matching headline.
- Extraction schema is now 5 so older cached stories progressively refresh through the new source rules.

## Google News strategy

Google News is intentionally supplemental rather than the only ingestion source. Its RSS/topic format is undocumented and Google article links can be redirects. Direct publisher feeds/pages remain the reliable core, while Google News discovers extra London publishers automatically.

## Image focal points

This does not use heavyweight face/object recognition. Pillow downsizes each image and calculates a high-contrast visual-saliency centroid with a slight centre bias. The resulting `image_focus_x` and `image_focus_y` values are used as CSS `object-position` for the square card crop. It is fast enough for GitHub Actions and degrades to a centred crop if an image cannot be analyzed.
