# London News

A static local-news index for London, Ontario. The public site is generated by Astro and hosted on GitHub Pages. A scheduled GitHub Action runs the Python collector, normalizes recent stories into `data/news.json`, and commits the refreshed dataset.

## Included sources

The starter source file includes Global News London, CBC News London, London Free Press, CTV News, 106.9 The X, City of London Newsroom, London Police Service, and London Fire Department.

Edit `scripts/sources.py` to add, remove, or change sources.

## Run locally

Requirements: Node.js 22+ and Python 3.12+.

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
python scripts/fetch_news.py
npm install
npm run dev
```


## Deploy

1. Create a public GitHub repository and upload this project. A public repo keeps GitHub Pages available on the free plan.
2. Make sure your default branch is named `main`.
3. Open repository Settings, then Pages.
4. Under Build and deployment, choose `GitHub Actions` as the source.
5. Push to `main`, then run the `Refresh and deploy` workflow once from the Actions tab if you want an immediate refresh.
6. The same workflow fetches the latest stories, builds Astro, and deploys GitHub Pages.

The refresh and deploy workflow runs twice an hour at minutes 7 and 37. GitHub scheduled workflows can be delayed during busy periods, so the schedule deliberately avoids the top of the hour.

## How collection works

RSS is preferred whenever a publisher provides it. Page-based sources use a generic link discovery pass, then Trafilatura plus page metadata to extract a short summary and other useful metadata. The site stores a normalized index. Headlines open on a local London News story page first, with clear attribution and a link to continue to the original publisher. Full publisher articles are not copied into the site.

The collector keeps up to 750 recent stories so the site can preserve a useful local archive even when a feed only exposes a small number of current items.
