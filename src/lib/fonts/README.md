# Inter 4.1 variable fonts

These files are the official Inter 4.1 variable web fonts from the Inter project:

- `InterVariable.woff2`
- `InterVariable-Italic.woff2`

The font files are stored unchanged from the `rsms/inter` v4.1 release source.
Inter is licensed under the SIL Open Font License 1.1. See `OFL.txt`.

Source: https://github.com/rsms/inter/tree/v4.1/docs/font-files
